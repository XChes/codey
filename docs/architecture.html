Codey 当前产品架构

32 个主要逻辑节点：从项目进入、会话编排到每个 Agent 独立 SRT，再回到文件审查和持久化。

1 · 全产品组件与关系

青色是 UI，绿色是 Main 服务，黄色是可信运行平台，玫红是安全边界，紫色是持久化；实线为调用，橙色虚线为事件/委派，玫红虚线为权限或凭证。

2 · Sandbox 开启、复用、临时替换与销毁

Sandbox 在 agent.boot 时开启，不在 conversation 创建时开启；Lead 可以缓存，Subagent 结束立即释放。

COMPONENT COUNT

  • 24 runtime/service components inside the product.
  • 8 durable or external nodes: DB, Keychain, roots, sessions, review, config, GitHub and model APIs.
  • Stored conversations are data; only selected/running/short-idle agents own live SRTs.

TRUST & ISOLATION

  • Renderer talks only through the context-isolated typed bridge.
  • Electron Main and Agent Host are trusted; only Pi Worker and descendants are inside SRT.
  • Local/Worktree chooses the execution root; SRT independently enforces process access.

CURRENT BOUNDARY

  • Implemented GitHub integration currently stops at repository list and clone.
  • Merge, push and pull-request delivery are not implemented yet.
  • No global concurrent-agent limit exists; SRT is beta and macOS sandbox-exec based.
